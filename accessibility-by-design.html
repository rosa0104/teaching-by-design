Accessibility by Design: Six Small Changes That Make a Big Difference

What it took to make a two-page learning object accessible, and why passing an automated check is not the goal.

Teaching by Design · 4 min read
On this page

Why Accessibility Matters

Accessible digital content is not simply a technical requirement; it determines whether learners can participate independently in an educational experience. Accessibility supports students who use assistive technology, but thoughtful design can also improve clarity and usability for everyone. Rybin Koob et al. (2022) emphasize that digital accessibility benefits all users, while Huss (2022) found common accessibility problems on school websites, including missing alternative text, confusing links, and poor color contrast. These findings reinforced an important lesson for me: accessibility needs to be considered during design rather than after a learner encounters a barrier.

What the Learning Object Already Did Well

I evaluated a two-page learning object titled Orchards and Vineyards. The original document had several positive features. The body text was readable, most text appeared as dark text on a light background, images were placed near the information they supported, and the content generally followed a logical reading sequence. However, visual appearance alone does not guarantee accessibility. WebAIM (n.d.) explains that Word documents need meaningful structure and alternatives that assistive technologies can interpret.

Six Changes I Made

  1. I created a true heading structure. The title and section labels looked like headings visually, but they were not coded as headings. I applied Word Heading styles so screen-reader users can navigate the document structure.
  2. I added meaningful alt text to the orchard image. Its existing description was a temporary computer file path rather than information a learner could use.
  3. I added descriptive alt text to the grape image, identifying the cluster of purple grapes growing on a vine.
  4. I corrected the graft-union image description. The revised alt text identifies the graft union and the arrow pointing to the healed graft.
  5. I removed color-only emphasis. Terms such as grafting, scion, and rootstock appeared in red. I changed them to black, bold text so emphasis does not depend on color perception and contrast is improved.
  6. I restructured the grafting procedure. Three sequential actions were embedded within a paragraph. I converted them into a true numbered list, making the process easier to scan while also giving assistive technology meaningful list structure.

How I Evaluated Accessibility

Three resources or modes are especially useful for accessibility review. First, Microsoft Word’s Accessibility Checker can identify issues such as missing alternative text and structural concerns while a document is being developed. Second, WebAIM provides practical guidance for Word documents, including headings, alternative text, lists, links, contrast, and color use (WebAIM, n.d.). For webpages, WAVE can identify many WCAG-related errors and make potential barriers easier to inspect. Third, automated checking should be paired with manual review, including keyboard navigation and, when possible, screen-reader testing. Rybin Koob et al. (2022) demonstrated the value of testing digital tools with actual screen-reader technology rather than relying only on automated evaluation.

A Change in Perspective

This activity changed how I think about accessibility. One particularly revealing issue was that the images technically contained descriptions, but those descriptions were temporary computer file paths rather than meaningful alternatives. An automated process might detect that a description field exists without determining whether it actually helps a learner.

Accessibility therefore requires both tools and professional judgment. For educators and instructional technologists, the goal should not simply be to “pass” an accessibility check. The goal is to design content that learners can perceive, navigate, understand, and use as independently as possible.
